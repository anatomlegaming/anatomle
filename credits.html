Human Skeleton 3D Model
anatomytool.org

The interactive 3D skeleton used throughout Anatomle was originally sourced from AnatomyTool (anatomytool.org). At the time of download, the model was made freely available under a Creative Commons license. We are deeply grateful to the creators for sharing this resource openly. Without it, Anatomle would not be possible.

Note: anatomytool.org is currently unavailable. We are unable to link directly to the original source at this time. Should the site return, we will update this attribution accordingly.

⚖️ CC BY-SA 4.0 — Creative Commons Attribution-ShareAlike

Derivative work disclosure: The original model has been modified for use in Anatomle. Modifications include: mirroring of right-side bones to create a complete bilateral skeleton, re-export and optimisation of the GLB file format, and programmatic mapping of individual mesh nodes to a custom adjacency graph used by Anatomle's game engine. These modifications were made solely to enable the interactive gameplay experience. All derivative work is shared under the same CC BY-SA 4.0 license in accordance with the ShareAlike requirement.
